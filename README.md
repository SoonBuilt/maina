# Maina

Copy a voice from half a minute of talking, then make it read anything you type: English, Hindi or Urdu. Free for Mac and Windows, and it all runs on your own computer.

**Download:** [maina.soonbuilt.com](https://maina.soonbuilt.com), or the latest release on the right.

This repository only holds the installers. Maina is made by [Soonbuilt](https://soonbuilt.com).

Only copy voices you're allowed to: your own, or someone who has said yes. Every clip Maina makes carries an inaudible watermark marking it as AI-made.
